# Saltline — English original, touch/PWA package

**Saltline 原版英文触屏包**：游戏本体是 Anthropic 工程师 Felix Rieseberg 于 2026-11-09 公开的 Claude artifact——由 Claude Fable 5.2 一次性生成的第一人称射击游戏。本包只做了 PWA 打包（安装、离线、全屏横屏），`game.js` 与 `game.css` 是从原版单文件 HTML 中**逐字节提取**的，游戏代码一字未改；校验指纹见 `source-manifest.json`。打包结构参照了 limingxuan960824 为中文换皮版所做的触屏移植，特此注明。

The game itself is the original work published by Felix Rieseberg (Anthropic), generated by Claude Fable 5.2. This package changes no game code — it only wraps the original for touch devices as an installable, offline-capable PWA.

## 怎么运行 / How to run

必须通过 HTTP 打开（`file://` 双击无法启用离线与安装功能）。任选一种：

```bash
# 在本文件夹目录下：
python3 -m http.server 8000
# 或
npx serve .
```

然后在 iPad 的 Safari 里打开 `http://<电脑的局域网IP>:8000` → 分享 → **添加到主屏幕**，之后即可全屏、离线游玩。

## 操作 / Controls

触控由游戏本体自带：左侧拇指移动、右侧拇指转向，屏幕按钮开火 / 瞄准 / 换弹 / 跳跃 / 交互。桌面浏览器可用键鼠（WASD + 鼠标，R 换弹，按住 E 切断中继）。

## 任务 / Objective

Cut the three uplink relays, then reach the extraction point. 切断三处上行中继，抵达撤离点。
